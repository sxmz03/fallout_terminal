# Assets and attribution

- `payload/fonts/RobCoCaseHeavy-Regular.ttf`: modified VT323. Renamed
  RobCoCaseHeavy; heavier strokes, lowercase-to-capital glyph appearance and
  marked uppercase glyphs. Original copyright: 2011, The VT323 Project Authors
  (peter.hull@oikoi.com). Distributed under `payload/fonts/OFL.txt`.
- `payload/logo.png`: the exact final background from the original terminal
  project. AI-assisted composition derived from the owner's supplied
  “Neon Vault-Tec Terminal Screen.png”; green Vault-Tec lettering/emblem on a
  dark canvas. It is bundled to reproduce that setup.
- `payload/startup-animations/standard.gif`: the exact GIF used by the original
  terminal project. Original creator/source and an explicit redistribution
  licence were not recorded in the surviving project files.
